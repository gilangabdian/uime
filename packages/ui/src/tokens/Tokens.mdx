# Design Tokens (`uime`)

A simple, personal token setup for `uime`—built just for fun around **frosted glass surfaces**, **soft 1px top highlights**, and **fluid spring motion**.

## 1. Playground

## 2. How to Use

You don't need any complex setup. Whenever you import a component from `uime`, its CSS variables are injected automatically:

```tsx
import { Button } from "uime";
```

*(Optional)* If you want to load the stylesheet statically in your root layout or copy a component like `shadcn/ui`, you can also import `"uime/styles.css"`.

### Switching Dark & Light Mode
- **Dark Mode (Default):** Active by default on `:root` or `data-theme="dark"`.
- **Light Mode:** Add `data-theme="light"` to `<html>` or any wrapper `<div>`.

---

## 3. The Frosted Glass Recipe

Every glass surface in `uime` uses three simple CSS variables together:

```css
.card {
  background: var(--uime-surface-glass-elevated);
  backdrop-filter: blur(var(--uime-blur-lg));
  border: 1px solid var(--uime-border-subtle);
  box-shadow: var(--uime-shadow-glass);
}
```
